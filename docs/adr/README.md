# Décisions d'architecture

Les ADR (Architecture Decision Records) documentent les choix structurants du
projet, leur contexte et leurs compromis. Les dates indiquent la rédaction,
pas nécessairement la date à laquelle le choix a été fait.

Les décisions existantes sont décrites rétrospectivement ; les alternatives
présentées sont des points de comparaison, pas nécessairement des solutions
effectivement évaluées par l'équipe. Lorsqu'une décision change, on ajoute un
nouvel ADR et on indique dans l'ancien par lequel il est remplacé.
